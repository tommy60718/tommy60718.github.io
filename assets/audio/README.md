# Audio Files Directory

Place your audio files in this directory. Due to GitHub's file size limitations, it's recommended to:

1. Keep audio files small (under 50MB)
2. Consider using external hosting for larger files
3. Use formats like MP3 or OGG for better compatibility

Note: The music player is currently configured to use sample tracks from Free Music Archive.
If you want to use your own audio, update the playlist in `/assets/js/main.js`.
